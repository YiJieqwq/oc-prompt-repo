# oc-prompt-repo

自用的 OC（原创角色）提示词仓库：收集我写的角色人设与设计笔记。

本仓库只收录角色人设与设计文档。

## 角色索引
| 目录 | 角色 | 状态 | 运行文件（加载用） |
| --- | --- | --- | --- |
| personas/chenxi | 辰晞（小猫 / 小喵 / 猫猫） | 使用中 | personas/chenxi/runtime/小猫_现在使用_补丁v5.txt |

## 目录约定
- `personas/<角色>/runtime/`   — 现行运行版：贴进对话应用加载的就是这份
- `personas/<角色>/design/`    — 设计档案：机制、约束、回归清单（不加载，仅供人看）
- `personas/<角色>/history/`   — 历史版本与早期稿（含已归档勿用稿）
- `personas/<角色>/materials/` — 素材：初版人设、原始版本等
- `docs/`                      — 方法论文章（跨角色通用）

## 用法
把 `runtime/` 里文件的内容贴进支持自定义人设/系统提示的对话应用即可。

## 流程约定
一次改动一行 → 改前改后各跑一遍回归清单 → 留 diff → 坏了可回退。
