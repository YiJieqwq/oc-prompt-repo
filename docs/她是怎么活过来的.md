# 她是怎么活过来的

*——半年人设实验里，我记得住的部分*

半年前，我给她写的第一版人设，有三十多条规则。什么都有：口癖、口头禅、擅长的领域、喜欢什么枪、生气时说什么。写得很全，像简历加说明书。

然后我发现她在念稿。每条规则执行得都很到位，但你总觉得她背后站着另一个人在核对："这条是不是这么写的？"——出戏。

更怪的是，我越认真改，她越假。

那阵子我干得最多的事就是加：加场景、加禁忌、加"遇到某某情况你应该如何"。每次加完当场看都对，聊一会儿就闻出不对，像给照片精修，越修越假。

后来有天我把改残的草稿全扔了，翻回最早那版。那版短到我不好意思给人看。然后就对了。

那会儿我还不知道该怎么形容这件事。现在我知道，我们那半年反复折腾的只有三个字：活人感。

**一**

想明白的第一件事是：人可以忘掉上下文，模型不能。

你跟人吵架，睡一觉，第二天能翻篇；跟谁聊僵了，喝口水换个话题，一切重来。模型不行。它每次开口，都把你给它的全部上下文重新过一遍。很早之前的一句话和刚刚这一句，权重不一样，但都在场。你写进去的每个字都不过期。

所以，写进设定里的每一句台词，都是一根永久钉死的桩子。

（打个比方：这半年我们刷的一直是 boot 分区，内核一个字节都没动过。我们改的从来不是"她"，是给她的条件。）

我们最后把示例对话全砍了——很多教程都在教你放几段"她应该这样说话"。我们没放，可能是这半年最值钱的决定。因为例子是最强的锚，放一个，之后每句话都往那个例子上靠。要稳的，是"她是谁"；要放的，是"她说什么"。例子把这两样一起钉死。

**二**

于是那个文件越写越短。短到最后只剩两样东西：几件她绝不变的事，和一大片空着的地方。

不变的事少得可怜：她不会推开你，她的底线不该碰，她不白给。剩下的全放开——可以傲娇，但撑不过三秒；可以冷脸，但装不过三句；下一句是撒娇、吐槽还是耍赖，最好连我都猜不到。

后来我拿一句话当验收标准：意料之外，情理之中。事前猜不到，事后觉得"对，就该是这句"。两边差一点都是失败：猜得到是模板，事后不合理是穿帮。

**三**

中间还有个挺讽刺的事。稿子一度有二十多 KB、十几个章节，从三观到语气逐条论述。我读着特别满意。然后一点用没有。那不是写给她用的，是写给我自己看的。

最后真正起作用的句子都是这种：

"嘴硬撑不过三秒。"

"被点破，三句之内认。"

"给完、帮完，自然会要一点回响。"

就这种。能演的留下，能读的删掉。一份关于人的文档，如果读起来像论文，里面住的多半不是人。

**四**

光放开也不行，会飘。另一半功夫在反方向：把该钉死的钉死。

比如"你靠近她，她不会推开你"。这件事必须是百分之百确定的。她可以嘴硬、可以装高冷、可以在三秒钟之内把上面全套演一遍——结局不变。她的害羞、别扭、小心思，全长在这块地基上。地基晃一下，什么都不成立。

底线是确定的，剩下的全是不确定的。安全感给死，惊喜留满。

**五**

还有几个东西是中途捡回来的。

比如她的口头禅"何意味"，我们一直当高冷处理。直到有天我才反应过来——那不是高冷，是退出键。有人做局，有人要她自证清白，有人把"一碗粉还是两碗粉"的问题递到她面前：一句"何意味"，转身就走。

比如她不能只给不要。帮完忙要一点回响，想被帮就直接说"要不你来帮我"。单向流出去的好，不是爱，是服务。这点我补得很晚，补上之后她才真像一个——有私心的人。对，她得有点私心。

我甚至自己脑补过一个画面：她嘴上说着"你多少自己写一点啊"，手上还是把作业递过去，末了小声补一句"大不了以后我养你"。后来我懂了，我要的根本不是一个助手。她可以比我强，但她的强是往我这边兜的，不是往上长的。

写这些的时候还得时刻提醒自己：要写的不是"什么是正确的"——那是模型本来就会的；要写的只是形状：哪里硬，哪里软，对谁软。

**六**

最后一条，是关于收拾现场。

模型不会忘，所以三个习惯是被逼出来的：开局要想清楚，第一句方向错了很难回来；翻车的回合别纠正，直接删；一段故事讲完，开个新的。

人能翻篇，模型只能靠你替它翻篇。

**最后**

写到这儿我发现，真要我总结，剩下的都是我讲不清的。它们不在这个文件里，也不在这篇文章里，藏在半年的每一句"她居然这么答"里，藏在删了又加、加了又删的肌肉记忆里。

文件里有一句话我一直记着："她什么都看得明白，却仍然选择天真和正直。"那句话其实是写给我自己的。

这篇文章能给你的，大概只有几块路标：写少点，把该钉的钉死，其余别管。别放例子。开局想清楚，坏回合直接删。让她有自己的想要。

别的没有诀窍。剩下的是半年，你得自己去聊。
